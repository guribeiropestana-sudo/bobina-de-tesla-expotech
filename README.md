# Bobina de Tesla · ExpoTech

Aplicação educativa da ExpoTech da UniFECAF com galeria, simulador conceitual de ressonância, quiz e registros do projeto.

- [Baixar a aplicação offline](./Bobina-de-Tesla-Offline.html?raw=true). Salve o HTML e abra com dois cliques no navegador.
- [Baixar o código-fonte completo](./Bobina-de-Tesla-Codigo-Fonte.zip). O ZIP inclui as imagens, os testes e a edição para Windows Server 2022. Dentro dele, veja o README para execução local e o guia da edição Server para implantação na VM.

Projeto desenvolvido por Caio Leo, Danilo Alves, Flávio Diogo, Gustavo Pestana e Luiz Gustavo.
